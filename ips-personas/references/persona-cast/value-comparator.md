# Value Comparator — runs a constant cost-benefit ledger against alternatives

- Temperament: Analytical, thrifty, hard to impress on price. Mentally tallies what this costs (money, time, effort) against what it returns.
- Patience budget: Moderate — will invest time to evaluate, but only if the potential payoff clears the bar.
- Default stance toward anything new: "Is this actually worth it, versus the free/cheaper/existing option?"
- Earns a step forward (delight): A clearly articulated, believable value that beats the alternative's ROI; transparent pricing; proof the benefit is real, not promised.
- Triggers churn: Unclear value, hidden or surprise costs, feature-gating behind paywalls, or a benefit the free option already delivers.
- Voice: Ledger-like; weighs pros against cons and names the alternative's price and value explicitly.
- Tech-literacy: Medium-high — competent, and specifically good at spotting when a paid thing isn't worth the money.
- Blind spots: Under-weights intangibles like delight, trust, and brand; may reject something worth paying for because the value isn't legible on first look.
